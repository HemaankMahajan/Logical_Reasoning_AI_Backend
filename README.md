## 🎯 Overview

Modern LLM integrations often treat inference as a black box, hiding intermediate deduction steps and leaving token consumption unmonitored until quotas are unexpectedly exhausted. **Logical Reasoning AI** solves both challenges by providing:
1. **Transparent Reasoning Inspection:** Separates final synthesized outputs from raw internal reasoning traces generated by **NVIDIA Nemotron** models.
2. **Real-Time Token Governance:** Tracks `prompt_tokens`, `completion_tokens`, and `reasoning_tokens` per request, enforcing automated daily completion quotas (`10,000 tokens/day`) with proactive threshold alerting (`80%` warning, `100%` circuit-breaker lock).

---

## ✨ Key Features

- **Dual-Pane Reasoning Workspace:** Side-by-side inspection of synthesized AI responses and raw chain-of-thought reasoning logs, paired with instant per-prompt token distribution charts.
- **Automated Token Quota Governance:**
  - Tracks daily completion token velocity against a configurable `10,000` token ceiling.
  - Triggers real-time UI notification badges at **80% (`8,000` tokens)** and programmatically disables prompt submission at **100% (`10,000` tokens)** to prevent quota overruns.
- **Multi-Granularity Analytics Dashboard:** Interactive `Chart.js` visualizations aggregating token utilization across **Daily**, **Monthly**, and **Yearly** timeframes with dynamic filtering.
- **Stateless JWT Authentication & Session Security:**
  - Custom `JwtFilter` intercepting protected routes and validating signed Bearer tokens.
  - Authenticated in-app credential rotation and profile management.
- **Data Portability & Lifecycle Controls:**
  - One-click client-side **CSV export** of complete prompt/response histories and token metadata.
  - **Danger Zone History Wipe** featuring decoupled data retention—allowing users to purge sensitive prompt text while optionally preserving aggregate dashboard analytics.
- **Adaptive Design System:** Fixed-navigation responsive layout supporting both a high-contrast **Neon Dark Theme** and a clean **Enterprise Light Theme**.

## 🏗️ System Architecture & Design

The platform follows a clean **N-Tier Decoupled Client-Server Architecture**:

```text
+-------------------------------------------------------------------+
|                        React SPA (Vite + MUI)                     |
|  - Axios Request Interceptors (Auto-injects JWT Bearer Header)    |
|  - Real-time Quota Circuit Breaker & Notification State Engine    |
+---------------------------------+---------------------------------+
                                  | REST / JSON (HTTPS)
                                  v
+-------------------------------------------------------------------+
|                    Spring Boot Backend (REST API)                 |
|                                                                   |
|  [ Security Filter Chain ] ---> JwtFilter & Spring Security       |
|              |                                                    |
|              v                                                    |
|  [ Controller Layer ]      ---> AuthController, AIController      |
|              |                                                    |
|              v                                                    |
|  [ Service Layer ]         ---> Token Aggregation & Quota Check   |
|       |             |                                             |
|       |             +---------> [ External AI Inference Client ]  |
|       |                                  |                        |
|       v                                  v                        |
|  [ Spring Data JPA ]            NVIDIA Nemotron API Endpoint      |
+-------+-----------------------------------------------------------+
        | JDBC
        v
+-------------------------------------------------------------------+
|                          MySQL Database                           |
|  - Users (Credentials, Profile Metadata)                          |
|  - PromptHistory (Prompts, Responses, Reasoning, Token Metrics)   |
+-------------------------------------------------------------------+
```

### Key Architectural Decisions
- **Analytics Preservation on Deletion:** Rather than coupling dashboard metrics strictly to raw text rows, the deletion workflow supports retaining aggregate token counts so historical usage telemetry remains accurate even after sensitive prompt logs are purged.
- **Interceptor-Driven Auth:** Centralizing token injection in Axios (frontend) and `OncePerRequestFilter` (backend) keeps business logic controllers completely agnostic of authentication boilerplate.

## 🚀 Getting Started

### Prerequisites
- **Java Development Kit (JDK) 21** or higher
- **Node.js (v18+)** and **npm**
- **MySQL Server 8.0+**
- **NVIDIA API Key** (obtainable via [NVIDIA Build](https://build.nvidia.com/))

### 1. Database Setup
Create a MySQL database instance:
```sql
CREATE DATABASE logical_reasoning_ai;
```

### 2. Backend Configuration & Launch
1. Navigate to the backend directory:
   ```bash
   cd Logical-Reasoning-AI-Backend
   ```
2. Configure `src/main/resources/application.properties`:
   ```properties
   server.port=8080

   # MySQL Configuration
   spring.datasource.url=jdbc:mysql://localhost:3307/logical_reasoning_ai?useSSL=false&serverTimezone=UTC
   spring.datasource.username=your_mysql_username
   spring.datasource.password=your_mysql_password
   spring.jpa.hibernate.ddl-auto=update

   # JWT Security Configuration
   jwt.secret=your_256_bit_base64_encoded_secret_key_here
   jwt.expiration=86400000

   # NVIDIA AI API Configuration
   nvidia.api.key=your-api-key-here
   nvidia.api.url=your-api-url-here
   ```
3. Build and run the Spring Boot application:
   ```bash
   ./mvnw clean spring-boot:run
   ```

### 3. Frontend Configuration & Launch
1. Navigate to the frontend directory:
   ```bash
   cd Logical-Reasoning-AI-Frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```
4. Open your browser and navigate to `http://localhost:5173`.
